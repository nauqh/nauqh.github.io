how I run agent teams

a small dev team
on one machine

I build agent teams for work too large for a single session. A lead agent splits the task, assigns each worker its own git worktree and branch, and merges the results.

  1. 01

    plan

    The lead splits the job so no two workers share a file. I approve the split.

  2. 02

    spawn

    Each worker gets its own worktree, branch and terminal.

  3. 03

    brief

    A written brief per worker: the goal, its files, the tests to run.

  4. 04

    merge

    The lead reviews the code and merges. I review the feature.
